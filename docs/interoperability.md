# Interoperability

ATP is designed to complement:
- [Google A2A Protocol](https://github.com/google/A2A): trust proof in agent cards
- [SLSA](https://slsa.dev): provenance level factors into trust score
- [Sigstore](https://sigstore.dev): keyless co-signing of trust proofs ([Sigstore co-signature rules](../ATP-SPEC.md#431-sigstore-co-signature))
- [Certificate Transparency (RFC 6962)](https://datatracker.ietf.org/doc/html/rfc6962): compatible log structure
- [W3C DID Core](https://www.w3.org/TR/did-core/): agent identifiers
- [W3C Verifiable Credentials Data Model 2.0](https://www.w3.org/TR/vc-data-model-2.0/): ATX maps member for member onto the credential structure ([mapping, example and schema](../README.md#verifiable-credential-form))
